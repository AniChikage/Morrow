# 开始使用 Morrow

[文档首页](README.md)

## 从源码安装

需要 macOS 14+、Node.js 24+、npm 和 Xcode Command Line Tools。使用 Codex 时，还需安装并登录 Codex Mac App；Morrow 不要求另填模型 API Key。

```bash
git clone https://github.com/AniChikage/Morrow.git
cd Morrow
npm ci
npm run build:app
bash scripts/install-app.sh
open "$HOME/Applications/Morrow.app"
```

构建输出为 `dist/Morrow.app`，安装默认写入 `~/Applications/Morrow.app`。安装器先复制并校验完整签名，再替换应用；回退副本只在安装期间保留，成功后清理。也可给安装脚本传入其他目标目录。构建会准备并校验 Node 24 运行时，安装后的 App 自带该运行时。当前产物使用本机 ad-hoc 签名；正式对外分发还需要 Developer ID 签名与 Apple 公证。

## 第一个项目

1. **打开项目文件夹**，选择现有目录，写下持续目标，并在「项目说明」里写下你知道而仓库里没有的东西（目标与成功标准、目标用户与场景、当前阶段与已知问题、优先级与不做的事、资源与入口、约束与红线、需要你决定的事；「插入模板」会填入这些标题）。Codex 每轮都会读取它并优先于自己的推断，但不会修改；之后可在项目页的「项目说明」标签随时修改，改动后进行中的判断会被要求重新评估。新项目会准备一个暂停的「自主推进」频道，自动轮次默认沿用 App 中已关联任务的权限与审批设置，每日最多 32 轮；接入本身不会启动执行。需要收紧时，可在频道设置中改为只读或工作区写入。
2. **创建并关联 Codex App 任务**。在 App 为同一项目目录创建任务，发送首条消息并保持打开，然后在 Morrow 频道选择「关联 App 任务」或「关联对话」。运行时页会核对：App 已安装 → App 已连接 → 任务已关联 → 关联任务可用。Morrow 不再安装启动转接程序，也不直接新建 App 任务。App 必须保持运行；需要完整访问时请在 App 中设置。
3. **点击「开始工作」**。Codex 结合项目目标与现状选择下一步，通过项目工作接口维护判断、看板和证据。想给自己留出 Codex 额度时，在设置（`⌘,`）的「保留给自己的额度」里填一个窗口和百分比；想限制某个项目时，在项目属性栏的「额度」里设上限（按 Morrow 归因的估算）。达到后 Morrow 不再发起新的自动轮次，频道显示「等待额度重置」，普通对话不受影响。
4. **在同一对话中指导**。可发送文字和图片，运行中追加指导，处理受支持的原生审批与提问，也可随时暂停。Codex 提出问题时，频道页会在顶部显示问题和答题框，项目页属性栏的「待回答」会列出所有等待回答的频道。
5. **审阅上线材料**。需要发布时，到项目「上线确认」查看具体改动、预期收益、证据、回退方案和发布后的观察计划，再决定是否发布。发布目标是你自己提供的 HTTP 接收端，或是你写好并提交在项目里的脚本（`local-script`，例如 `scripts/release-local.sh`）：脚本内容在提议时被封存，页面上可以逐字读完将要执行的内容，只有你确认后 Morrow 才以固定的最小环境执行那份封存副本。

欢迎页提供明确标注的示例工作区，示例频道不会执行。`⌘N` 打开项目，`⌘K` 搜索，`⌘,` 打开设置，`⌘B` 切换侧栏。
